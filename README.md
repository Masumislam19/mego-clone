# MegoClone — Video Chat MVP

WebRTC + Socket.IO দিয়ে বানানো একটা বেসিক random/interest-based video chat app (Mego/Azar/Omegle ধরনের)।

## যা যা আছে
- Interest-tag ম্যাচিং (না দিলে random match)
- Real-time HD video call (peer-to-peer, WebRTC)
- সাথে টেক্সট চ্যাট
- Skip / Next বাটন দিয়ে নতুন পার্টনার খোঁজা

## যা যা এখনো নাই (পরের ধাপে যোগ করা লাগবে)
- ইউজার লগইন/অথেনটিকেশন
- প্রোফাইল, ভার্চুয়াল গিফট/কয়েন সিস্টেম
- কন্টেন্ট মডারেশন (নগ্নতা/হয়রানি ডিটেকশন)
- Block/Report ফিচার
- ডাটাবেজ (এখন সব in-memory, সার্ভার রিস্টার্ট হলে সব ডাটা হারিয়ে যাবে)

## লোকালি রান করা

```bash
npm install
npm start
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। দুইটা আলাদা ট্যাব/ব্রাউজার/ডিভাইস থেকে খুললে একজনের সাথে অন্যজন ম্যাচ হবে (নিজে নিজের সাথে টেস্ট করতে পারবেন)।

## গুরুত্বপূর্ণ টেকনিক্যাল নোট

### TURN সার্ভার (ফ্রি স্টান দিয়ে সব ক্ষেত্রে কাজ নাও করতে পারে)
এখানে ফ্রি পাবলিক STUN সার্ভার (`stun.l.google.com`) ব্যবহার করা হয়েছে, যেটা বেশিরভাগ সময় কাজ করবে যখন দুই ইউজার একই নেটওয়ার্কে না বা সাধারণ NAT-এর পেছনে থাকে। কিন্তু strict corporate/mobile NAT-এর ক্ষেত্রে TURN সার্ভার লাগবে (ফ্রি না — যেমন Twilio, Xirsys, বা নিজে coturn সেটআপ করে হোস্ট করতে পারেন)।

### স্কেলিং
এখন matchmaking queue আর pairing সব in-memory (একটা সার্ভার প্রসেসে)। একাধিক সার্ভার ইনস্ট্যান্স চালাতে চাইলে Redis দিয়ে shared state রাখা লাগবে।

### HTTPS বাধ্যতামূলক
`getUserMedia` (ক্যামেরা/মাইক এক্সেস) ব্রাউজার শুধু `localhost` অথবা HTTPS-এ allow করে। প্রোডাকশনে ডিপ্লয় করলে অবশ্যই SSL সার্টিফিকেট (Let's Encrypt ফ্রি) লাগবে।

## ফ্রি ডিপ্লয়মেন্ট অপশন (টেস্টিং/MVP-এর জন্য)
- **Render.com** / **Railway.app** — ফ্রি টায়ারে Node.js app হোস্ট করা যায় (সীমিত ব্যান্ডউইথ/আওয়ার)
- **Glitch.com** — ছোট প্রজেক্ট টেস্ট করার জন্য ভালো
- বড় স্কেলে গেলে এগুলোর ফ্রি টায়ার যথেষ্ট হবে না — তখন AWS/GCP-তে পেইড সার্ভার লাগবে

## পরবর্তী ধাপ (Roadmap)
1. ইউজার অথ (Firebase Auth ফ্রি টায়ার দিয়ে শুরু করা যায়)
2. Block/Report বাটন যোগ করা
3. MongoDB/PostgreSQL দিয়ে persistent user profile
4. TURN সার্ভার সেটআপ (coturn সেল্ফ-হোস্ট করলে ফ্রি, নাহলে পেইড সার্ভিস)
5. Content moderation (Google Cloud Vision ফ্রি টায়ার আছে, তারপর পেইড)
